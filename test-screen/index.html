Screen Tester

Cek layar untuk dead pixel, warna, dan bleed panel.

Gunakan warna penuh seperti putih, hitam, merah, hijau, dan biru untuk mencari pixel mati atau stuck pixel. Mode grid membantu mengecek area kecil dengan lebih teliti.

Kontrol Tes Layar

Pindah warna, aktifkan grid, atau jalankan mode auto-cycle untuk mengecek panel lebih cepat.

Gunakan mode hitam untuk melihat backlight bleed, lalu lanjutkan ke warna penuh untuk menemukan dead pixel atau stuck pixel.

Panduan Cek

Lihat titik yang selalu hitam, selalu putih, atau selalu merah/hijau/biru. Jika hanya muncul pada satu warna, itu biasanya stuck pixel.
