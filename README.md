# Yoso Komputer

Landing page statis untuk usaha servis komputer dan laptop `Yoso Komputer`.

## File

- `index.html`
- `styles.css`
- `script.js`

## Deploy ke GitHub Pages

1. Upload semua file ke repository GitHub.
2. Buka `Settings` repository.
3. Masuk ke menu `Pages`.
4. Pada bagian `Build and deployment`, pilih `Deploy from a branch`.
5. Pilih branch yang dipakai, misalnya `main`, lalu folder `/root`.
6. Simpan, lalu tunggu sampai link website GitHub Pages aktif.
