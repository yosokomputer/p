Privasi & Permission

Browser akan meminta izin sebelum kamera aktif. Jika izin ditolak, halaman ini tidak akan bisa menampilkan preview sampai permission diberikan kembali dari browser.

Tips: jika setelah klik tombol tidak muncul video, cek icon kamera di address bar browser dan pastikan akses webcam diizinkan untuk halaman ini.
